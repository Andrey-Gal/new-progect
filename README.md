# New Project — матричный тренажёр для Андрея

Небольшой, но аккуратный учебный проект для прокачки фронтенда и Git.

## Что здесь есть

- 🎨 Светлая и тёмная темы (переключатель + сохранение в `localStorage`)
- ✨ Кнопка «Нажми меня» и зелёная магия рядом с ней
- 💬 «Цитата дня», которая меняется каждый день года
- 👋 Анимация приветствия и волны
- 🧱 Карточка с учебными целями и блок с навыками
- 📜 Плавное появление блоков при скролле (`scroll-reveal`)
- ⬆️ Кнопка «Наверх» со сглаженным скроллом
- 🐰 «Ушки Нео» — декоративные матричные подсветки вокруг заголовка

## Технологии

- Чистый **HTML + CSS + JavaScript**
- Без фреймворков и сборщиков
- Git + GitHub Pages для деплоя
